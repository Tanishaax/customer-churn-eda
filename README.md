# Customer Churn - Exploratory Data Analysis

## Project Overview

This project analyzes customer data to identify patterns
associated with customer churn and retention.

## Objectives

- Analyze customer churn
- Clean and prepare the dataset
- Perform exploratory data analysis
- Identify factors associated with churn
- Generate customer retention insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

- Data cleaning
- Missing value analysis
- Duplicate analysis
- Outlier treatment
- Skewness analysis
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Correlation analysis

## Key Insights

- Month-to-month contracts show the strongest churn pattern.
- Tenure is broadly similar between churn groups.
- Monthly charges show considerable overlap between churn groups.
- Internet Service categories show different churn patterns.
- Tenure and TotalCharges have a strong positive correlation.

## Conclusion

The analysis provides insights into customer behavior
and factors associated with churn, which can help businesses
develop targeted customer retention strategies.
